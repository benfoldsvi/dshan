HOW TO REPUBLISH AFTER UNPUBLISH
================================
1. Upload/commit all files to the repository.
2. Push to the main branch.
3. Open GitHub repository → Actions.
4. Select "Build and deploy GitHub Pages".
5. If it did not automatically run, click "Run workflow" → main → Run workflow.
6. Wait until BOTH build and deploy show green check marks.
7. Then Settings → Pages will show the live site URL again.

IMPORTANT
=========
Selecting Settings → Pages → Source → GitHub Actions alone does NOT deploy a site.
There must be a successful Pages deployment workflow after an Unpublish.
